# MVP

## Must
Organização, bairro, propriedade, usuários, MFA, RBAC, mapa, câmeras, sensores, gateways, online/offline, eventos, alertas, incidentes, evidências, auditoria, ativos, API e PWA.

## Should
WhatsApp homologado, SMS, detecção de pessoa/veículo, perda/obstrução de vídeo e regras por horário.

## Future
Leitura de placas, drones, integrações governamentais autorizadas e biometria autorizada.
